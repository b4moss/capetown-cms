# バージョンの付け方

原則として **SemVerベース** とする。

- 1の位: MAJOR - 後方互換性を持たない破壊的変更または大規模な変更
- 小数点第1位: MINOR - 後方互換性を持つ新機能の追加
- 小数点第2位: PATCH - バグフィックス、または軽微な改善
- suffix
  - 必要があればsuffixをつけて良い
  - 小数点第2位の後に、`-{slug}.n`とする。
  - slugの内容は、主に以下の通り
    - doc: ドキュメントの更新
    - site: ドキュメントサイトの更新
    - rc: リリースキャンディデート
- `v0.n.0`は、正式リリース前。この場合、小数点第1位の更新があっても、破壊的変更は許容される。
- `v1.0.0`へのアップデートは、PO(プロダクトオーナー)の判断で行う。
- バージョンを上げたときは、必ずGitタグを打つ。この場合、mainブランチで打つこと。
